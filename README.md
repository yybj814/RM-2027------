## 参数推导
TIM2 挂 APB0，定时器时钟 = 72MHz。
目标：1 个计数 = 1µs → 计数频率 1MHz → PSC = 72-1 = 71。
舵机要求 50Hz，周期 20ms = 20000µs → ARR = 20000-1 = 19999。
验算：72MHz ÷ (71+1) ÷ (19999+1) = 50Hz 

## 角度换算
0°=500µs，180°=2500µs，1 计数=1µs：
CCR = 500 + 角度/180 × 2000
两端各留 2° 余量，代码中角度限幅 2°~178°，换算后 CCR 约 522~2478，
